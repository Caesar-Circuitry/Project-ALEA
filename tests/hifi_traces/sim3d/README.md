# tests/hifi_traces/sim3d

JSON traces recorded from dsim's real 3D hive code (`hive3d.ts`, `contacts3d.ts`, the Rapier3d
layer, driven through `step3d`) at the pinned commit in `alea/hifi/DSIM_VERSION`. Generated by
`../record_3d/record_hive3d.mts`; never edit by hand. `constants3d`, `statics3d`, `joint_tick` and the `loads_*` files are replayed by
`tests/test_hifi_hive3d_*.py` (the `loads_*` replay feeds the recorded angle and angular velocity;
see `alea/hifi/PORTING.md`); `g409_contacts.json` is not replayed. `tests/test_hifi_traces3d_schema.py`
checks structure and the pin.

| File | What it holds |
|---|---|
| `constants3d.json` | config constants the 3D hive reads, mass properties, cell boxes |
| `statics3d.json` | torque and `insideCell` functions on grids |
| `loads_no_tip_blue.json` | per-tick traces of loads below the tip table (detent holds) |
| `loads_tip_blue.json` | per-tick traces of loads that tip (breakaway, release, TIP) |
| `loads_red.json` | red hive, 8P tips and 7P holds |
| `joint_tick.json` | `hive3dJointTick` on staged hive states |
| `g409_contacts.json` | G409 contact pass, robot away vs under the down cell |

Field meanings, caveats and the exact rerun commands are in `../README.md` (section "3D hive
traces"). dsim is PolyForm Noncommercial; see `alea/hifi/LICENSE-dsim`.
