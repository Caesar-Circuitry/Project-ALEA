# TeamCode (FTC module)

The FTC TeamCode module: Android code that runs on the Control Hub. It holds the sample OpMode and the ALEA helpers in `src/main/java/org/firstinspires/ftc/teamcode/alea/`. This is NOT the competition robot.

Build it from `robot/`:

```
cd robot
./gradlew assembleDebug
```

The logging keys (`Alea/...`) are defined in `docs/robot-interface.md`. Add a key there before you log it.
